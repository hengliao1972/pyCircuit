\chapter{UOP Engine Microcode Size Analysis}
This appendix estimates the microcode body size if the PTO tile instruction portion is implemented on Davinci OoO entirely through WO/WM microcode. The estimate counts only UOP Engine-generated micro instruction instances. It does not count CPU front-end decode logic, implementation-local operand rename state, decoded metadata state, vector beat-buffer expansion, or scalar/control instructions outside the tile instruction surface.

The size rule is fixed for this manual:
\[
\texttt{code\_size\_bytes} = \texttt{micro\_instruction\_count} \times 8
\]
Each micro instruction instance is one 64-bit WO/WM microcode word: \texttt{WM} occupies bits \texttt{31:0}, and \texttt{WO} occupies bits \texttt{63:32}.

\section{All Tile Instruction Estimate}
For the full PTO tile instruction surface, the UOP Engine microcode estimate uses 69 tile instruction entries and 1,900 micro instruction instances. At 8 bytes per 64-bit micro instruction, the full tile instruction microcode body is 15,200 bytes, or 14.84 KiB. This all tile instruction figure is an upper-bound estimate from the wider tile instruction corpus; the current Vec subset above is the exact count after removing type and constant constructors from the encoded micro instruction stream.

The conclusion is that the full tile instruction UOP Engine microcode is approximately 15 KiB, while the current Davinci Vec subset is approximately 2.96 KiB. The Davinci microassembler expands 64-bit WO/WM micro instructions with Tile Metadata RAT state into VEC beat words; that expansion does not add microcode body bytes.
